# Grüezi Deutsch — How the app works

Interactive slide deck: **https://bajpaih22.github.io/gruezi-deutsch-deck/**
Use ← → to move between slides, Option/Alt+P for presenter view with notes.

## Change the slide text on GitHub

1. Open [`src/content.js`](src/content.js) and click the pencil icon (Edit this file).
2. Change the text between the quotes. Keep the quotes, commas and brackets as they are.
3. Click **Commit changes…** → **Commit changes**.
4. Wait about a minute (watch the **Actions** tab turn green), then reload the deck.

If the Actions run turns red, a quote or comma is probably missing; open the run to see the line.

## Edit locally

```bash
npm install
npm run dev
```
